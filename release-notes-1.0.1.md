# Rework Time 1.0.1

Считает время в программах Windows. Локально, без сети и телеметрии.

## Что нового в 1.0.1

- **Трей**: крестик больше не закрывает программу — окно прячется в трей,
  счёт продолжается. В меню иконки: «Показать» и «Выход».
- **Один экземпляр**: повторный запуск не создаёт второй счётчик, а поднимает
  окно уже работающей копии.
- Иконка приложения вшита в exe, ярлыки и exe подписаны версией 1.0.0.0 в ресурсах.

## Что умеет

- Считает время по активному окну (опрос раз в секунду, WinAPI).
- Простой: 2 минуты без ввода — время не идёт.
- История в SQLite: `%APPDATA%\REWORK\ReworkTime\usage.db`.
- Топ-5 за день / неделю / месяц / год: подиум с растущими колонками, корона
  чемпиону, настоящие иконки программ.
- Пауза одной кнопкой, себя в статистике не считает.

## Установка

1. Скачай `ReworkTime-win64.zip` из assets.
2. Распакуй в любую папку.
3. Запусти `ReworkTime.exe` — Qt внутри, ставить ничего не нужно.

Windows 10/11 x64.

## Сборка из исходников

```
build.cmd
```

Нужны Qt 6.12 (MinGW kit), CMake ≥ 3.21, Ninja.

## Ограничения (честные)

1. Считается только активное окно: второй монитор без фокуса не засчитается.
2. Браузер — как процесс, а не сайт (заголовок окна пишется в базу).
3. Некоторые UWP-приложения отдают окно `ApplicationFrameHost`.
4. Незавершённая сессия при аварийном завершении остаётся с `end_ts = start_ts`.

C++17, Qt 6.12 (Qt Quick/QML), SQLite. Лицензия MIT.
