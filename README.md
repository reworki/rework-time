# REWORK TIME

Считает, сколько времени ты проводишь в каждой программе. Локально, без сети.

- **1 секунда** — гранулярность опроса активного окна (WinAPI: `GetForegroundWindow` → PID → exe).
- **Отошёл** — если 120 секунд нет ввода мыши/клавиатуры, время не капает.
- **SQLite** — каждая сессия это строка `(app, title, start_ts, end_ts)`; топ считается одним запросом.
- **Периоды** — день / неделя (с понедельника) / месяц / год.
- **Трей** — закрытие окна скрывает в трей, выход через меню.

## Сборка

```
build.cmd
```

Или руками: CMake + Ninja + Qt 6.12 (MinGW kit) — параметры уже прописаны в `build.cmd`.

Запуск: `build\reworktime.exe`.

## Где данные

`%APPDATA%\REWORK\ReworkTime\usage.db` (SQLite, WAL). Удалить файл = обнулить статистику.

Схема:

```sql
CREATE TABLE sessions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  app TEXT NOT NULL,
  title TEXT,
  start_ts INTEGER NOT NULL,   -- epoch, секунды
  end_ts   INTEGER NOT NULL
);
```

## Ограничения (честные)

1. Считается **только активное** окно: игра на втором мониторе без фокуса не засчитается.
2. Браузер показывает процесс (`chrome`), а не сайт — заголовок окна сохраняется в `title`,
   по нему потом можно строить «топ страниц» приблизительно.
3. UWP-приложения иногда склеиваются в `ApplicationFrameHost` — нужен маппинг.
4. Незавершённая сессия (аварийное завершение) останется с `end_ts = start_ts` — не страшно,
   теряется максимум минуты.

## Структура

```
src/tracker.*   — опрос окна и простоя (WinAPI)
src/store.*     — SQLite: сессии, агрегаты
src/mainwindow.*— окно, бары, периоды, трей
src/main.cpp    — запуск, тёмный заголовок окна
```

## Версия 2 — Qt Quick / QML

Интерфейс переписан на QML (Qt 6.12): подиум с растущими колонками, корона над
первым местом, настоящие иконки программ, плавные анимации высот и ширины.
C++ остаётся бэкендом: сэмплер, SQLite, агрегаты, иконки.

- `src/backend.*` — мост C++ → QML (`backend.top`, `backend.total`, `backend.status`).
- `qml/Main.qml` — весь интерфейс.
- Иконки: PNG-кэш в `%APPDATA%\REWORK\ReworkTime\icons`, отдаётся QML как `file://`.
  Так сделано специально: провайдер картинок Qt в отдельном потоке падал на
  `QFileIconProvider`, а `data:` URL в `Image` не рисовались.
- Старая версия на Qt Widgets лежит в `src/legacy-widgets` (не собирается).

Ограничение текущей версии: закрытие окна выходит из приложения (трея пока нет).
