# Rework Time 1.0.0

Учёт времени в программах Windows. Локально, без сети и телеметрии.

## Что умеет

- **Считает время по активному окну** — опрос раз в секунду через WinAPI
  (`GetForegroundWindow` → PID → путь к exe), с подсчётом простоя: если 2 минуты
  нет ввода, время не капает.
- **Хранит истории в SQLite** — каждая сессия это строка `(app, title, start_ts, end_ts)`.
  База: `%APPDATA%\REWORK\ReworkTime\usage.db`.
- **Топ-5 за день / неделю / месяц / год** — подиум с растущими колонками, корона
  чемпиону, настоящие иконки программ.
- **Пауза** — одна кнопка, время в это время не пишется.
- **Себя не считает** — когда открыто окно статистики, счётчик не тикает.

## Установка

1. Скачай `ReworkTime-win64.zip` из assets.
2. Распакуй в любую папку.
3. Запусти `ReworkTime.exe` — Qt-библиотеки уже внутри, ставить ничего не нужно.

Требуется Windows 10/11 x64.

## Сборка из исходников

```
build.cmd
```

Нужны: Qt 6.12 (MinGW kit), CMake ≥ 3.21, Ninja. Всё остальное скрипт подставит сам.

## Ограничения (честные)

1. Считается только **активное** окно: игра на втором мониторе без фокуса не засчитается.
2. Браузер определяется как процесс (`chrome`, `brave`), а не сайт; заголовок окна
   сохраняется в базе, по нему потом можно строить приблизительный «топ страниц».
3. Некоторые UWP-приложения отдают окно `ApplicationFrameHost` — нужен маппинг.
4. Незавершённая сессия при аварийном завершении остаётся с `end_ts = start_ts`
   (теряется максимум секунды).
